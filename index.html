Methodology & Sources

Explanation of data handling and constraints.

Public Data Source

Data is sourced via the YouTube Data API v3. Views, likes, and comment counts are public statistics. Metrics reflect point-in-time retrieval.

Owner Data Constraints

In adherence to data integrity requirements, metrics such as CTR, watch time, and demographics require explicit YouTube Analytics API authorization. No estimates are generated.

YouTube View Counting (Aug 2026 update)

Per YouTube Data API documentation, viewCount includes views when a video begins to play, including autoplay/hover interactions. Analysis considers this baseline shift.
